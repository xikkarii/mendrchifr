# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ

## «МеандрШифр» v1.0 — система симметричного шифрования на основе меандров

---

### 1. Назначение

Программа «МеандрШифр» предназначена для шифрования и дешифрования текстовых
сообщений и файлов с использованием ключа, формируемого из комбинаторной
структуры меандра. Дополнительно программа визуализирует меандр и выводит
статистику работы.

### 2. Системные требования

**Минимальные:** ОС Linux / Windows / macOS, процессор 1 ГГц, ОЗУ 512 МБ,
100 МБ свободного места.
**Рекомендуемые:** Windows 11, процессор 2 ГГц, ОЗУ 2 ГБ, экран 1366×768.

### 3. Запуск программы

- **Windows:** запустить `MeandrCipher.exe`.
- **macOS:** открыть `MeandrCipher.app`.
- **Linux:** запустить исполняемый файл `MeandrCipher`.

После запуска открывается главное окно с панелью параметров, полями ввода/вывода,
областью визуализации и логом.

### 4. Главное окно

```
┌─────────────────────────────────────────────────┐
│ MeandrCipher v1.0                               │
├─────────────────────────────────────────────────┤
│ Порядок меандра: [3] [Сгенерировать]  Меандр №[1]│
├─────────────────────────────────────────────────┤
│ [Зашифровать][Расшифровать][Загрузить][Сохранить]│
│ [Экспорт ключа]                                  │
├─────────────────────────────────────────────────┤
│ Исходный текст:  [____________________________]  │

└─────────────────────────────────────────────────┘
```

### 5. Порядок работы

#### 5.1. Шифрование текста

1. Задайте **порядок меандра** (число от 1 до 10) в поле «Порядок меандра».
2. Нажмите **«Сгенерировать»**. Программа построит все меандры данного порядка,
   отобразит первый из них в области визуализации и выведет ключ в лог.
3. При необходимости выберите другой меандр в списке **«Меандр №»** — это
   изменит ключ.
4. Введите текст в поле **«Исходный текст»**.
5. Нажмите **«Зашифровать»**. Результат (в шестнадцатеричном виде) появится в
   поле **«Результат»**, а в лог будут выведены время и энтропия.

#### 5.2. Дешифрование текста

1. Сгенерируйте **тот же меандр** (тот же порядок и тот же номер), что
   использовался при шифровании. Это критично: другой меандр даст другой ключ
   и неверный результат.
2. Вставьте шестнадцатеричный шифротекст в поле **«Исходный текст»**.
3. Нажмите **«Расшифровать»**. Исходный текст появится в поле «Результат».

#### 5.3. Работа с файлами

- **«Загрузить»** — открыть `.txt` (как текст) или `.enc` (как двоичные данные,
  отображаются в hex) в поле исходного текста.
- **«Сохранить»** — сохранить содержимое поля «Результат». При выборе
  расширения `.enc` hex-данные сохраняются в двоичном виде, при `.txt` — как
  текст.

#### 5.4. Экспорт ключа

Кнопка **«Экспорт ключа»** сохраняет параметры текущего меандра (порядок,
паросочетания, последовательность обхода, ключ SHA-256) в файл JSON. Это
позволяет задокументировать использованный ключ.

### 6. Визуализация меандра

В области визуализации отображаются:

- **горизонтальная пунктирная ось** — прямая, которую пересекает меандр;
- **синие дуги** — верхние участки кривой (над осью);
- **красные дуги** — нижние участки кривой (под осью);
- **чёрные точки с номерами** — точки пересечения (1…2n);
- **подпись «Обход»** — последовательность прохождения точек, из которой
  формируется ключ.

### 7. Типичные сообщения и их причины

| Сообщение | Причина | Действие |
|-----------|---------|----------|
| «Сначала сгенерируйте меандр» | Не нажата кнопка «Сгенерировать» | Сгенерируйте меандр |
| «Введите текст для шифрования» | Пустое поле исходного текста | Введите текст |
| «Некорректный hex-формат шифротекста» | При дешифровании введён не hex | Проверьте данные |

### 8. Рекомендации

- Для надёжного дешифрования **запоминайте порядок и номер меандра** —
  это и есть секретный ключ. Можно сохранить их через «Экспорт ключа».
- Шифротекст всегда отображается в hex — копируйте его целиком.
- Программа не повреждает исходные файлы: запись идёт только при явном
  нажатии «Сохранить».
